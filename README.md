## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/manaswisk/Python-Generative-AI-Internship.git
```

Navigate to the project directory:

```bash
cd Python-Generative-AI-Internship
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

Install the dependencies for an individual task using its `requirements.txt` file.

## 🔐 API Key Configuration

Some projects require a Google Gemini API key.

1. Obtain an API key from Google AI Studio.
2. Store it in a local `.env` file.
3. Never upload API keys or `.env` files to GitHub.
